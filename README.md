### Kernel-Code-Defect-Management-Platform
### 项目名称
实现一种可以筛选内核代码缺陷扫描工具扫描结果，减少误报，准确识别内核代码缺陷的管理平台

### 导师信息
窦志冲, douzhichong@ieisystem.com

### 难度
中

### 分类
系统维护工具

### 题目要求
可通过代码管理平台进行扫描内核代码，识别内核代码缺陷时，一次扫描可能会扫描出上万条结果，这些结果中会有很多的误报，而每次识别这些扫描结果将会浪费大量的人力。因此，我们想实现一种筛选扫描结果的代码缺陷管理平台，通过代码扫描工具扫描出来的信息，可以直接输入给代码缺陷管理平台，代码缺陷管理平台可以筛选扫描结果，最终给输出给研发人员真正的内核代码缺陷，帮助研发人员优化内核代码，提升内核代码质量，该平台要求筛选规则显示可见，筛选规则可自定义添加和删除，筛选准确率至少达到70%

### 特征
不限制语言

### 预期目标
1、平台应该显示可见筛选规则
2、平台应该具备筛选规则自定义添加和删除功能
3、平台的筛选准确率至少达到70%
4、平台具备接收Coccinelle、coccicheck 和 sparse等开源工具的扫描结果的接口
